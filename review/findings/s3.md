### FOUND-004 — DSSE-KMS described incorrectly

- **Category:** ERROR
- **Verification status:** CONFIRMED
- **Confidence:** HIGH
- **Location:** Security — Server-Side Encryption — DSSE-KMS
- **Original claim:** "Dual-layer encryption – Data encrypted client side and server side … No additional charge … Client requests KMS to generate data encryption key (DEK)…"
- **Issue:** DSSE-KMS is dual-layer **server-side** encryption (two independent AES-256 layers applied by S3), not client-side plus server-side. It is not free; it costs more than SSE-KMS. The described client-side envelope workflow is client-side encryption with KMS, not DSSE-KMS.
- **Official evidence:** "DSSE-KMS applies two layers of encryption to objects when they are uploaded to Amazon S3… First layer: your data is encrypted using a unique data encryption key (DEK) generated by AWS KMS; Second layer: encrypted again using a separate AES-256 key managed by Amazon S3." "DSSE-KMS incurs higher charges due to increased computational overhead and additional AWS KMS operations." KMS keys must be in the same Region as the bucket.
- **Source:** Using dual-layer server-side encryption with AWS KMS keys (DSSE-KMS) — https://docs.aws.amazon.com/AmazonS3/latest/userguide/UsingDSSEncryption.html
- **Assessment:** Multiple statements in the bullet contradict the documentation. The DEK/plaintext/encrypted-DEK walkthrough should move under Client-Side Encryption if retained.
- **Suggested correction:** "DSSE-KMS: two layers of server-side AES-256 encryption, first with a KMS-generated DEK, second with an S3-managed key. For compliance needing multilayer encryption. Higher cost than SSE-KMS. KMS key must be in the same Region." Relocate the client-side DEK steps to Client-Side Encryption.
- **SAA-C03 relevance:** MEDIUM
- **Further action:** None

- **Issue:** The notes never state that Object Lock only works in versioned buckets and applies to individual object _versions_ (new versions and delete markers can still be added). - **Assessment:** Important conceptual omission for exam questions on WORM/immutability.
